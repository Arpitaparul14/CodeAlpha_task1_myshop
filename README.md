# MyShop - E-commerce Website
Built with Django (Python) as CodeAlpha Internship Task 1

## Features
- Product listings with images
- Shopping cart
- User registration & login
- Order processing with Cash on Delivery
- Customer delivery details (Name, Phone, Address, City, Pincode)
- Order history & cancel order
- Search bar
- Admin panel
- Mobile responsive

## How to run
1. Clone the repository
2. Install dependencies:
   pip install django pillow

3. Run migrations:
   python manage.py migrate

4. Run the server:
   python manage.py runserver

5. Open browser at:
   http://127.0.0.1:8000

6. Register a new account and start!
7. Go to /admin/ to add products
